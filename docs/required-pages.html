Project Structure SOP

Required Pages

Every project ships with the core set below. Optional pages are added based on project scope — confirm which are in scope at kickoff so QA and Go-Live can be scoped correctly.

Core pages — required on every project

PageSlugNotes
Home/Primary landing page
About / Company/about-usCompany story, team, mission
Services / Products/services or CMS collectionStatic or CMS-driven depending on scope
Contact/contactMust include a working form — verify in QA
404 Not Found/404-not-foundWebflow system page — style must match brand
Password / 401/401-passwordOnly relevant if staging password protection is used
Style Guide/style-guideInternal reference for Client-First components; unindexed, can be unpublished after hand-off

Common optional pages

Add per project scope — call these out explicitly in the project brief.

Blog / Insights

CMS collection + template + list page.

Case Studies / Portfolio

CMS collection + template + list page.

Team

Static or CMS-driven (Team Member collection).

Pricing

Static comparison or plan cards.

Careers / Jobs

Often a CMS collection for open roles.

FAQ

Standalone page, or a section reused across pages.

Legal

Privacy Policy, Terms of Service, Cookie Policy.

Landing pages

Campaign-specific; usually excluded from main nav and noindexed.

Scope this at kickoff, not mid-build. The Go-Live checklist checks every page listed as "in scope" in the brief — pages added late are the easiest thing for QA to miss.
