Project Structure SOP

New Project Setup Checklist

Run through this at kickoff, before content or design work begins, to seed a new Webflow project on this standard.

  1. Create the project and apply the Client-First starter/base styles (utility classes, core structure, containers, section padding sizes).
  2. Confirm required pages exist; add optional pages from the brief and organize them into Page folders if the site has more than ~6–8 pages.
  3. Set up CMS Collections: singular names, plain-English fields, references defined, a short collection purpose note in the hand-off doc.
  4. Build or confirm the Style Guide page reflects the project's typography, color, and component conventions.
  5. Set up global components (nav, footer, shared CTA) as Webflow Components/Symbols, following folder naming conventions.
  6. Rename any uploaded placeholder assets before they're used in the design.
  7. Confirm 404 and password-protection pages are styled and in the project.
  8. Add this SOP and the CMS Collections summary to the project's hand-off documentation.
  9. Bookmark the QA Checklist and Go-Live Checklist for this project so the team knows what "finished" looks like before build starts.
