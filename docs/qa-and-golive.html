Project Structure SOP

QA & Go-Live Connection

This SOP defines the structure a project should have. Two downstream workflows verify and ship that structure.

WorkflowWhat it checksWhen to run it
QA Checklist Functional and structural correctness against this SOP: pages, naming, CMS, responsiveness, forms, links, accessibility, performance After a build is "structurally done" (see Definition of Done), before client review
Go-Live Checklist Launch readiness: domain/DNS, redirects, SEO settings, analytics, integrations, backups, final client sign-off After QA has passed and the client has approved
