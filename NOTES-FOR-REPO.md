# WebsiteSquirrel Docs

A static, dependency-free documentation site (HTML/CSS/JS — no build step).

Open `index.html` in a browser to view it locally, or drag this whole folder into
https://app.netlify.com/drop, or push it to GitHub and enable GitHub Pages.

See the in-site "How This Site Works" page (README.html) for how to add pages,
edit the sidebar, and restyle the site.
