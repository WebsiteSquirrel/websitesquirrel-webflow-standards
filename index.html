WebsiteSquirrel Webflow Docs

One standard for how we structure, name, and organize every Webflow build — so any builder, QA reviewer, or client can open a project and understand it without a walkthrough call.

This is a living reference, the same way Finsweet's Client-First docs are for the Client-First class system. Edit the HTML files directly to keep it current — there's no build step. See the how this site works page if you're adding new content.

Style system baseline: everything here builds on Finsweet Client-First for class naming, folders, and page structure. This site applies Client-First specifically to WebsiteSquirrel's pages, CMS, components, and hand-off process — it doesn't repeat the full Client-First docs.
