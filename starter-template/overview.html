Starter Template Docs

This section will document the WebsiteSquirrel Webflow starter template once it's built: what's pre-built, how to clone it into a new project, and what to customize per client.

Status: Planned
How to fill this in: replace the sections below with real content as the template comes together. Everything else on this site (sidebar, TOC, prev/next links) will keep working — you're only editing content inside <main class="content">.

Suggested sections to write

  • What's included — pages, symbols, CMS collections, and interactions that ship with the template out of the box.
  • Cloning the template — the exact steps to duplicate it into a new client project (Webflow clone link, workspace, plan considerations).
  • What to customize first — color/typography variables, logo, nav links, footer, and any placeholder CMS content to swap out.
  • What not to touch — core structure, global symbols, or interactions that should stay as-is across projects.
  • Version history — a running log of what changed between template versions, so older client projects can be diffed against the latest.

Adding more Starter Template pages

This page is one entry in the Starter Template nav group. To add another — for example a page dedicated to the template's CMS setup, or its symbol library:

  1. Duplicate this file inside /starter-template/ and rename it, e.g. cms-setup.html.
  2. Update its <title>, <body data-page="..."> id, and heading.
  3. Add a matching entry to the Starter Template group in /assets/nav-data.js.

The sidebar, active-state highlighting, and Previous/Next footer links update automatically from that one file — see how this site works for the full pattern.
